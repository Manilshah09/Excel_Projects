# Excel Fundamental Booster Project

## Overview
This project is an Excel practice workbook created to learn and apply common Excel formulas using practical datasets.

## Sheets
- **Students** – Student marks, grades, averages, age, and filtering.
- **Products_Sales** – Product sales, discounts, and lookup practice.
- **Employees** – Employee details, joining dates, and salary lookup.
- **Monthly_Sales** – Monthly salesperson sales with INDEX/MATCH and OFFSET.
- **Formula_Practice** – Text functions, discounts, and INDIRECT practice.
- **Project_Guide** – List of tasks and their objectives.

## Functions Practiced
- IF, AND, OR
- COUNTIFS, SUMIFS, AVERAGEIFS
- VLOOKUP, XLOOKUP, XMATCH
- INDEX, MATCH
- UPPER, LOWER
- INDIRECT, OFFSET
- TODAY
- ROUND, CEILING, FLOOR
- FILTER

## Tools Used
- Microsoft Excel
- Excel formulas and functions
